# Module 4: Python Crash Course

## Modulning maqsadi

Bu modul Python dasturlash tilining asosiy tushunchalarini o'rgatishga qaratilgan. Talabalar Python tilida samarali dasturlash uchun zarur bo'lgan barcha asosiy ko'nikmalarni o'rganadilar.

## Modul tarkibi

### 1. Python asoslari (1-python-basics)
- **Satrlar (Strings)**: Matn bilan ishlash, string methodlari
- **Ro'yxatlar (Lists)**: Ma'lumotlarni saqlash va boshqarish
- **Shartlar (Conditionals)**: if, elif, else operatorlari
- **Looplar (Loops)**: for va while tsikllari

### 2. Funksiyalar va modullar (2-functions-modules)
- **Funksiyalar**: Kod qayta ishlatish, parametrlar va return
- **Scope**: O'zgaruvchilar ko'rish doirasi
- **Import**: Modullarni import qilish
- **Kutubxonalar**: Python standart kutubxonalari va uchinchi tomon kutubxonalari

## O'quv materiallari

- `lecture.ipynb` - Asosiy ma'ruza materiallari
- `practical.ipynb` - Amaliy mashqlar
- `homework.ipynb` - Uy vazifasi
- `datasets/` - Amaliy ishlar uchun ma'lumotlar to'plami

## O'quv natijalari

Bu modulni tugatgandan so'ng talabalar quyidagilarni qila olishadi:

1. **Python sintaksisini tushunish va qo'llash**
2. **String va list ma'lumot turlari bilan ishlash**
3. **Shartli operatorlar va tsikllarni qo'llash**
4. **Funksiyalar yozish va chaqirish**
5. **Modullar va kutubxonalar bilan ishlash**
6. **Python kodini tuzilgan va samarali yozish**
