### 2. Ro'yxatlar (Lists)

### 3. Shartli operatorlar (Conditionals)
- if, elif, else
- Mantiqiy operatorlar
- Nested conditions

### 4. Tsikllar (Loops)
- for loop
- while loop  
- Loop control (break, continue)
