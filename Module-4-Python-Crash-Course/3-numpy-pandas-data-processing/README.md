# NumPy va Pandas bilan Ma'lumotlar Ishlash

## Maqsad

Python da ma'lumotlar tahlili uchun eng muhim kutubxonalar bo'lgan NumPy va Pandas bilan ishlashni o'rganish.

## Mavzular

### 1. NumPy (Numerical Python)
- NumPy asoslari va arraylar
- Array yaratish va shakllantirishlar
- Indexing va slicing
- Mathematical operations
- Broadcasting
- Array manipulation

### 2. Pandas (Python Data Analysis Library) 
- Series va DataFrame
- Ma'lumotlarni yuklash va saqlash
- Indexing va selecting
- Filtering va querying
- Data cleaning va transformation
- Grouping va aggregation
- Merging va joining

### 3. Amaliy misolar
- Real ma'lumotlar bilan ishlash
- Statistik tahlil
- Ma'lumotlarni vizuallashtirish
