# Funksiyalar va Modullar

## Maqsad

Python da funksiyalar yaratish, modullar bilan ishlash va kod tashkil etish usullarini o'rganish.

## Mavzular

### 1. Funksiyalar (Functions)
- Funksiya yaratish va chaqirish
- Parametrlar va argumentlar
- Return operatori

### 2. Funksiya parametrlari
- Positional argumentlar
- Keyword argumentlar  
- Default parametrlar
- *args va **kwargs

### 3. Variable Scope
- Global va local o'zgaruvchilar
- Scope qoidalari

### 4. Modullar (Modules)
- Import operatori
- Modullar yaratish
- Python standart kutubxonalari
